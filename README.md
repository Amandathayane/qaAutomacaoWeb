## 📌 Sobre o Projeto

O projeto **qaautomacaoweb** foi criado com o objetivo de aplicar na prática os conhecimentos adquiridos nas aulas da pós-graduação, com ênfase em automação de testes web. A automação é feita com Cypress, uma das ferramentas mais utilizadas para testes end-to-end modernos.

---

## 🧰 Tecnologias Utilizadas

- [Cypress](https://www.cypress.io/)
- [JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript)

## ✅ Pré-requisitos

Antes de iniciar, certifique-se de ter os seguintes itens instalados na sua máquina:

- [Node.js](https://nodejs.org/) (versão 18 ou superior recomendada)
- [Git](https://git-scm.com/)
- [Visual Studio Code](https://code.visualstudio.com/) ou outro editor de sua preferência

## 📥 Como baixar e rodar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Amandathayane/qaAutomacaoWeb.git
```

### 2. Acesse a pasta do projeto

```bash
cd qaAutomacaoWeb
```

### 3. Instale as dependências

```bash
npm install
```

---

## 🚀 Como executar os testes

### 🔹 Abrir a interface do Cypress

```bash
npx cypress open
```

Esse comando abrirá a interface gráfica do Cypress. Nela, você poderá visualizar e rodar os testes de forma interativa.

### 🔹 Executar os testes via terminal (modo headless)

```bash
npm run test
```

Esse script já está configurado no `package.json` para executar os testes diretamente no terminal, sem abrir a interface do Cypress.

---

## 📜 Scripts disponíveis

- `test`: Executa os testes em modo headless
